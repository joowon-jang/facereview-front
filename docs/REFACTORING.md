# 2026 리팩토링 상세 내역 (Frontend)

2023년에 개발한 프로젝트를 2026년에 장주원(Frontend)·김대선(Backend) 2인이 리팩토링한 내용 중, 프론트엔드의 개선 사항을 카테고리별로 정리한 문서입니다.

## 1. 빌드·툴링 현대화

**배경**: 2023년 프로젝트는 CRA(react-scripts 5) + Yarn Classic 기반으로, 빌드가 느리고 의존성이 노후화되어 있었습니다.

- **CRA → Vite 7 마이그레이션**: 개발 서버 기동과 빌드 속도를 크게 개선하고, `vite-tsconfig-paths`·`vite-plugin-svgr`로 기존 절대 경로 import와 SVG 컴포넌트 사용을 유지했습니다.
- **Yarn Berry(v4) 전환**: 패키지 관리를 Yarn Berry로 전환해 의존성 설치를 안정화했습니다.
- **런타임·언어 업그레이드**: React 18.2 → 19, TypeScript 4.4 → 5.9, react-router-dom·zustand·react-toastify 등 주요 의존성을 최신 메이저 버전으로 올렸습니다.
- **테스트·품질 도구**: Vitest 3 + Testing Library 기반 테스트 환경을 구축하고, ESLint 9(flat config)와 Prettier 설정을 정비했습니다. `any` 타입 경고 제거 등 타입 안정화도 함께 진행했습니다.

## 2. 데이터 페칭·상태 관리

**배경**: 페이지 컴포넌트마다 `useEffect` + `axios` 호출과 로딩 상태 관리가 흩어져 있어 캐싱·중복 요청 제어가 어려웠습니다.

- **TanStack Query v5 도입**: WatchPage를 비롯한 주요 페이지의 데이터 페칭을 React Query로 전환해 캐싱과 로딩·에러 상태 관리를 일원화했습니다.
- **무한 스크롤**: 메인 페이지의 카테고리별 추천 영상과 영상 검색 결과에 `useInfiniteQuery` 기반 무한 스크롤을 구현했습니다.
- **감정 도메인 로직 중앙화**: 여러 페이지에 흩어져 있던 감정 관련 상수·유틸리티를 `constants`/`utils`로 중앙화해 중복을 제거했습니다.

## 3. 인증·보안

**배경**: 기존에는 액세스 토큰 단일 인증이었고, 새로고침 시 로그인이 풀리는 문제가 있었습니다.

- **리프레시 토큰 기반 인증**: 백엔드와 함께 리프레시 토큰 발급·재발급(reissue) 플로우를 도입하고, 보안 로그아웃을 구현했습니다.
- **axios interceptor 통합**: 토큰 첨부와 만료 시 재발급을 interceptor 한 곳에서 처리하도록 통합해, 개별 API 호출부에서 인증을 신경 쓰지 않도록 했습니다.
- **토큰 재발급 경합 해결**: 여러 API가 동시에 401을 받아 각자 reissue를 호출하면서 토큰이 꼬이던 문제를, 재발급 요청을 단일화하고 대기 중인 요청들이 갱신된 토큰을 공유하도록 수정했습니다.
- **계정 관리 기능**: 이메일 인증, 비밀번호 변경, 회원 탈퇴 기능을 추가했습니다.
- **보안 헤더**: CSP를 포함한 보안 헤더를 정비했습니다.

## 4. 신규 기능

- **영상 검색**: 무한 스크롤을 지원하는 영상 검색 기능을 구현했습니다.
- **즐겨찾기(북마크) 페이지**: 영상을 북마크하고 모아 볼 수 있는 페이지를 신설했습니다.
- **로그인 안내 전역 모달**: 비로그인 상태에서 로그인이 필요한 동작 시 안내 모달을 전역으로 띄우도록 했습니다.
- **404 페이지**: 존재하지 않는 경로 접근 시 전용 페이지를 보여줍니다.
- **감정 타임라인 드래그 시킹**: 시청 화면의 감정 타임라인 그래프를 드래그하면 영상이 해당 구간으로 이동합니다. 정지 상태에서 시킹하면 정지 상태를 유지합니다.
- **시청 시간 초 단위 토글**: 마이페이지 시청 시간을 초 단위로 전환해 볼 수 있습니다.
- **삭제·비공개 영상 처리**: YouTube에서 삭제되거나 비공개된 영상을 목록에서 자동으로 숨기고, 직접 접근 시 모달 안내 후 리다이렉트합니다.

## 5. 디자인 개편·반응형 대응

**배경**: 2023년 디자인은 데스크톱 중심이었고, 페이지마다 여백·타이포그래피 기준이 제각각이었습니다.

- **디자인 시스템 정립**: 디자인 토큰, 3단계 브레이크포인트, 공통 레이아웃 셸을 정의하고 [DESIGN.md](../DESIGN.md)로 문서화했습니다. 페이지 레이아웃 오프셋을 통일하고 수직 마진을 단방향으로 정리했습니다.
- **전 페이지 플랫 디자인 리디자인**: 전 페이지를 플랫 디자인 기조로 리디자인했습니다.
- **모바일·태블릿 반응형**: 3단계 브레이크포인트 기준으로 타이포그래피·거터·컴포넌트 사이징까지 반응형으로 대응했습니다. 터치 디바이스에서 hover 스타일이 남는 문제는 `hover` 미디어쿼리 가드로 해결했습니다.
- **캐러셀 전환**: 가로 스크롤로 넘기던 영상 목록을 Swiper 기반 캐러셀로 교체하고, 로딩 스켈레톤 개수를 실제 그리드 열 수·캐러셀 브레이크포인트와 동기화했습니다.
- **시청 화면 컨트롤 재구성**: YouTube 기본 컨트롤을 끄고(`controls: 0`) 재생 토글·시크바·툴팁·전체화면 버튼을 커스텀으로 구현해, 감정 타임라인 그래프와 영상 컨트롤이 겹치지 않도록 상하 영역을 분리했습니다. 감정 그래프는 라인 차트로 전환하고 시간축 정렬을 바로잡았습니다.

## 6. 웹 접근성(a11y)

- **공용 컴포넌트 표준화**: TextInput을 `InputHTMLAttributes` 상속 + `forwardRef` + 표준 `ChangeEvent` 구조로 리팩토링하고, Button의 기본 `type="button"` 지정 등 네이티브 동작을 보장했습니다.
- **폼 사용성**: `aria-label`·`autocomplete` 속성을 보강하고, 회원가입 단계 전환 시 적절한 input에 자동 포커스되도록 했습니다. 댓글 입력에는 공백 검증과 Enter 저장을 지원합니다.
- **스크린 리더 대응**: 장식용 이미지의 `alt`를 정리하고, 로딩 상태를 알리는 Spinner 컴포넌트에 접근성 속성을 적용했으며, `<html lang>`을 `ko-KR`로 바로잡았습니다.

## 7. SEO·메타데이터

**배경**: SPA 특성상 모든 경로가 동일한 메타데이터를 반환해 검색 노출과 링크 미리보기가 불리했습니다.

- **정적 라우트 SSG 프리렌더링**: 빌드 시 `scripts/prerender.mjs`로 정적 라우트를 프리렌더링해 크롤러가 실제 콘텐츠가 담긴 HTML을 받도록 했습니다.
- **영상별 동적 OG**: 영상 상세 경로는 빌드 타임에 영상별 OG 메타데이터를 생성하고(`scripts/generate-og.mjs`), 썸네일은 `maxresdefault` 실패 시 `hqdefault`로 폴백합니다.
- **페이지별 메타데이터**: react-helmet-async로 전 페이지의 title·description·OG 태그를 정비하고 sitemap을 추가했습니다.
- **파비콘·매니페스트**: 파비콘과 웹 매니페스트를 최적화하고 캐시 무효화를 적용했습니다.
- **SPA 라우팅 대응**: 새로고침 시 404가 나던 문제를 Vercel catch-all rewrite로 해결했습니다.

## 8. 성능

- **코드 스플리팅**: Suspense + lazy 렌더링으로 초기 로딩 속도를 개선하고, 불필요한 preconnect를 제거했습니다.
- **불필요한 요청 제거**: VideoItem에서 다량의 불필요한 네트워크 요청이 발생하던 문제를 수정했습니다.
- **웹캠 캡처 주기 최적화**: 감정 분석용 웹캠 프레임 전송 주기를 0.2초에서 0.5초로 조정해 소켓 트래픽과 서버 부하를 줄였습니다.

## 9. 안정성·코드 품질

- **루트 ErrorBoundary**: 렌더 오류나 배포 후 청크 로드 실패 시 흰 화면 대신 복구 UI를 보여줍니다.
- **단위 테스트**: 상대 시간 표기 등 유틸리티에 단위 테스트를 추가했습니다.
- **SCSS 구조화**: SASS 7-1 패턴을 적용해 스타일 구조를 재편하고, 커스텀 훅을 폴더로 분리했습니다.
- **중복 제거**: WatchPage에 4중으로 중복돼 있던 감정 패널을 EmotionPanel 컴포넌트로 추출하는 등 컴포넌트를 분리했습니다.
- **정리**: 오타·불용 코드·미사용 export와 의존성을 정리하고, 잘못된 props·key 충돌 등 잠재 버그를 수정했습니다.
